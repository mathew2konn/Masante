| ADR-013 | Domaine Paiement = **microservice Java Spring Boot** (P5) | **Accepté** | CDC_06 §2 impose un domaine paiement **indépendant du cœur Laravel** : **Spring Boot 3.5 + PostgreSQL + Redis**, base propre, cycle de déploiement propre (`services/payment/`, hors workspace pnpm comme `services/api/`). **Exception assumée** à ADR-003 (Laravel/MySQL) : justifiée par la primauté du CDC_06 pour ce seul domaine (systèmes financiers). **Paiement SIMULÉ** (aucune passerelle Mobile Money réelle accessible — FT5) : la *structure* de domaine est correcte (interface `PaymentGateway` OCP + `SimulatedAdapter`, machine à états stricte CDC_06 §4.2 = enum `PaiementStatut` de `@masante/shared`, `Idempotency-Key` verrou Redis + unicité PG, journal d'audit **append-only à hachage chaîné**). **Frontière** : couverture CNAM/assurance, ticket modérateur et reste à charge calculés **uniquement** dans le service (jamais au front). | ADR-015 | [Cartes bancaires (P5.4a)](ADR-015-cartes-bancaires.md) | **Accepté** (simulé, FT5) | §5 carte : **frontière PCI** inviolable (jamais de PAN/CVV ; `FiltreAntiPan` Luhn→422, corps jamais loggé), **double modalité** OCP (`sim_tokenise` frictionless/3DS + `sim_redirige` redirection, zéro `if psp==`), **résultat 3DS jamais déclaré par le client** (`recupererStatut`/webhook = vérité, verrou pessimiste anti-double-capture), **webhook signé** HMAC sur corps brut avant désérialisation + fraîcheur (horodatage signé ±5 min) + anti-rejeu Redis + dédup `UNIQUE(psp,evenement_id)`, rejets **401/422 génériques** (anti-fuite). Sous-état `StatutCarte` **backend-only** projeté sur `PaiementStatut` (machine partagée jamais modifiée) ; `Montant(long,Devise)` confiné (XOF sans sous-unité). **Réconciliation à 2 sources** (registre local ⇄ vérité PSP) — vraie confrontation, distincte de l'auditeur interne ADR-014 — détection seule, idempotente. Vault « prêt §5.4 » (NTID/customer_id) mais **mandats récurrents non faits**. Prouvé G3 (build vert, 18 tests) + G2 live (11 vecteurs). |

| ADR-021 | [Identifiant National de Santé — porteur, algorithme, exposition (P6.1)](ADR-021-identifiant-national-sante.md) | **Accepté** | **Porteur = `membres_famille`** (le dossier patient ; `users` = compte, jamais porteur — sinon double identité de santé). **Auto-création du dossier titulaire en variante (c)** : à la complétion du profil, pas à l'inscription — `membres_famille` exige `date_naissance`/`sexe` que `RegisterRequest` ne collecte pas, et P1 est validé G5. Titulaire **hors quota** des 5 membres. **Algorithme MASANTE-NIS-MOD97** (ISO 7064) : préfixe converti A=10…Z=35 **inclus dans le calcul** → discrimination multi-pays sans code (`CIS…35` ≠ `SNS…04`) ; clé ∈ 02..98 ; modulo chiffre à chiffre (aucune dépendance). Détection **100 %** des erreurs d'un chiffre, des inversions voisines et des erreurs de clé. **Garde anti-divergence** : `vecteurs.json` unique consommé par la suite TS **et** PHP. **Anti-énumération** : `/nis/{nis}/verifier` ne consulte jamais la base. **Non-réutilisabilité** : `nis_journal` en `nullOnDelete`. Unicité du titulaire **déclarative** : MySQL refusant une colonne générée dérivée d'une colonne `ON DELETE CASCADE` (erreur 1215 constatée en G2), on pose colonne maintenue + `UNIQUE` + `CHECK` ; SQLite utilise un index unique partiel. Corrige l'exemple erroné d'ADR-001. |
| ADR-022 | MPI — détection **et** fusion après validation humaine (P6.2) | **Accepté** (G1) | Fusion **non destructive par pointeur logique** (`fusionne_vers_id`) plutôt que re-pointage des **18 tables** référençant `membres_famille` → défusion = remise à `NULL`, réversible par construction. Propriété du dossier fusionné traitée par **délégation croisée** sur la table `delegations` existante, sans nouveau modèle de droits. Résolution du pointeur en **un seul endroit** (`ResolveurDossier`). |
| ADR-023 | MPI — rapprochement flou sans `pg_trgm` (P6.2) | **Accepté** (G1) | MySQL 8.4 n'a ni `pg_trgm` ni Levenshtein natif, et `SOUNDEX` est calibré sur l'anglais (médiocre sur Kouassi, N'Guessan, Yao). Retenu : **clés de blocage indexées** + **scoring PHP pur** (Jaro-Winkler/Levenshtein) sur les seuls candidats bloqués. Seuils = **données** (`mpi_parametres`). Moteur **testable sans base**. |
| ADR-024 | Référentiels nationaux — enrichissement additif (P6.3+) | **Accepté** (G1) | Les tables existantes (`structures_sanitaires`, `medecins`, `medicaments`) sont **enrichies sur place** (identifiant national, district sanitaire, niveau de soins, numéro d'ordre, `pays_code`) plutôt que remplacées : P3 et P4 sont validés G5 et la règle est « corrections chirurgicales uniquement ». |
